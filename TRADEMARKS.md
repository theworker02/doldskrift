# Trademarks

**Doldskrift** and the project mark (`DSK_PROJECT_MARK` / logo) identify this open-source project.

The name is Swedish-rooted: *dold* (hidden / concealed) + *skrift* (writing / script). Using the name accurately is fine; do not twist the etymology into a claim that Open or Neural modes encrypt data.

## Logo (canonical asset)

| Asset | Role |
|-------|------|
| `assets/brand/logo-mark.svg` | Canonical mark (regenerate with `dold logo` / `dold brand`) |
| `site/public/logo-mark.svg` | Pages mirror of the same file |
| `packages/*/logo.svg` | Package README copies of the same mark |
| `assets/brand/social-card.svg` | OG / social preview (sync to `site/public/`) |

Prefer the SVG from `assets/brand/` (or regenerate it). Do not invent a substitute monogram. See [`docs/brand.md`](docs/brand.md).

Financial support links (thanks.dev / FUNDING.yml) identify sponsorship channels; they do not grant trademark rights or imply endorsement.

## Allowed without permission

- Accurate references to the software (“compatible with Doldskrift”, “built with Doldskrift”)
- Using the official logo to link to the official repository or site
- Screenshots of the software in reviews, talks, and documentation

## Please ask first

- Using Doldskrift as the name of a competing product or company
- Implying official endorsement or certification without agreement
- Modified logos that could confuse origin
- Using the mark to imply encryption / security properties the software does not claim

This document is guidance, not a full trademark registration statement.
Font and code licenses are separate — see `LICENSE*` and font metadata.
