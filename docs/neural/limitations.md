# Neural limitations

- No trained Gemma (or other) inference in default builds
- MGE/5 does not yet emit real path geometry from latent graphs
- DVE/2 does not yet run a real camera / raster pipeline
- Carrier-based observations are a CI stand-in, not production perception
- Gate capability types are policy stubs, not enforced crypto
- Neural difficulty is **not** confidentiality
