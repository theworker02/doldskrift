# Privacy

## Site demos (Lens, Black Page, Studio, Radio, Machine Reader)

By default:

- Encoding and decoding run **in your browser**
- Images you upload for local demos are processed **locally**
- No demo payload is uploaded to a Doldskrift server as part of ordinary site operation

Camera access (if enabled in a demo) requires explicit browser permission. Frames are not uploaded by default.

## Telemetry

This repository’s **static GitHub Pages** site does **not** currently include analytics or telemetry.

If analytics are added later, they will be documented here before enablement.

## CLI

The `dold` CLI does not phone home. It only reads/writes files and devices you point it at.
