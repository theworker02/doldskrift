# Contributors

This is the curated list of people and organizations recognized as Doldskrift contributors.

GitHub's automatic **Insights -> Contributors** graph also counts bot accounts that merge dependency PRs (for example Dependabot). Those bots are **not** project authors. Removing them from that graph requires rewriting git history, which this project does not do by default.

## Not listed as contributors

Automation and tooling identities are excluded from this curated list, including:

- Dependabot and other dependency bots
- CursorAgent and other coding-agent commit identities

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the required commit author identity for release and project work.
