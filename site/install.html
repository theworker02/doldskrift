Install 🇸🇪

Local toolchain first. Nothing here is published to crates.io / npm yet — clone the repo and build. After install, run dold doctor.

Open · Neural · Protected

One mental model for everything you download.

Open

Shipping codec, fonts, demos. Visual concealment ≠ encryption.

Neural

Foundation stubs + DeterministicBaseline. Not encryption. No Gemma weights in-repo.

Protected

Refuse stubs only. Real AEAD + Gate not shipping — do not treat as crypto.

Components

CLI (dold)

cargo install --path crates/doldskrift-cli — then dold doctor. Beta primary entrypoint.

Rust library

Path dep on crates/doldskrift. DSK/1 stable prototype; not on crates.io yet.

Fonts (MGE)

dold font build --out fonts/generated — candidate / evolving grammar.

WASM

Bindings → site/public/wasm/. Beta; Lens falls back to JS if missing.

JS / React SDK

packages/doldskrift-js + doldskrift-react. Vectors must match Rust.

Reader (DSK-R)

dold reader * — experimental / mock. No multi-GB weight auto-download.

Site (Pages)

npm run site:build → site/dist. Static demos only.

Quick start

cargo install --path crates/doldskrift-cli
dold doctor
dold version --verbose

echo "Hello from Doldskrift" | dold encode > message.dsk
dold validate message.dsk
dold inspect --json message.dsk
dold decode message.dsk

dold completion powershell   # or bash / zsh / fish
