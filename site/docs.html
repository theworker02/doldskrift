Docs 🇸🇪

Quick paths into the markdown docs and CLI. Normative wire rules live in spec/.

CLI

cargo install --path crates/doldskrift-cli
dold doctor
echo "hello" | dold encode > m.dsk
dold validate m.dsk
dold inspect --json m.dsk
dold decode m.dsk

Full surface: docs/reference/cli.md in the repo.

Rust

use doldskrift::{encode, decode};
let p = encode("hi")?;
assert_eq!(decode(&p)?, "hi");

Library docs: cargo doc -p doldskrift --no-deps.

JavaScript

import { encode, decode } from "@doldskrift/core";
decode(encode("hello agent"));
