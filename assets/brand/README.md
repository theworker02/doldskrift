SVG is the canonical source. Do not treat raster exports as masters.

| File | Use |
|------|-----|

The logo **is** a valid Doldskrift glyph: `DSK_PROJECT_MARK` at `U+E1F0`, generated by MGE/2.
See `docs/brand.md`. Name: Swedish *dold* + *skrift* → concealed script (`dold about`).

Colors: ink `#12161A`, teal `#0F6B5C`, paper `#F7F4EF`.

`favicon.ico`: prefer `favicon.svg`. If a legacy ICO is required, convert from `favicon.svg` with your icon toolchain — do not hand-edit a separate master.

### Regenerate & sync

```bash
dold logo --out assets/brand/logo-mark.svg
dold brand --out brand-kit   # mark + tokens + sync checklist
# keep consumers identical to the canonical mark:
cp assets/brand/logo-mark.svg site/public/logo-mark.svg
cp assets/brand/social-card.svg site/public/social-card.svg
cp assets/brand/logo-mark.svg packages/doldskrift-js/logo.svg
cp assets/brand/logo-mark.svg packages/doldskrift-web/logo.svg
cp assets/brand/logo-mark.svg packages/doldskrift-react/logo.svg
```

Regenerate `readme-demo.svg` with `cargo run -p doldskrift-font --example gen_readme_demo`.
